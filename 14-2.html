① JS 程序的基本结构 Program Structure

一段完整的 JavaScript 程序通常由以下步骤串联：

1
声明变量 — 用 let / const / var 保存数据
→
表达式计算 — 对数据做运算 / 调用方法
2
控制流程 — if / switch 决定走向，for / while 重复执行
→
函数封装 — 把可复用逻辑写成函数
3
输出结果 — console.log / 操作 DOM
→
结束
// 步骤 1：声明变量 const zhang_name = "张轩铭"; let zhang_score = 0; // 步骤 2：运算 zhang_score += 95; // 步骤 3：分支 + 输出 if (zhang_score >= 60) { console.log(zhang_name + " 及格！分数：" + zhang_score); } else { console.log(zhang_name + " 继续加油！"); }

② 循环 Loops

循环让一段代码重复执行。JavaScript 提供 for、while、do…while、for…of、for…in 等几种循环结构。

🔁 for 循环（C 风格）

最经典的计数循环：for(初始化; 条件; 更新)

// 打印 1 ~ 5 let zhang_result = ""; for (let i = 1; i <= 5; i++) { zhang_result += i + " "; } console.log(zhang_result);

🔁 while 循环

先判断条件，再执行循环体。条件为假时直接跳过。

// 累加 1+2+3+...+10 let zhang_sum = 0; let zhang_i = 1; while (zhang_i <= 10) { zhang_sum += zhang_i; zhang_i++; } console.log("1~10 的和 = " + zhang_sum);

🔁 do…while 循环

先执行一次循环体，再判断条件 → 至少执行一次。

// 即使条件一开始为 false，也会跑一次 let zhang_count = 0; do { zhang_count++; } while (zhang_count < 3); console.log("循环执行了 " + zhang_count + " 次");

🔁 for…of 循环

现代 JS 推荐！遍历数组、字符串等可迭代对象的元素值。

const zhang_fruits = ["🍎", "🍌", "🍇", "🍊"]; let zhang_line = ""; for (const fruit of zhang_fruits) { zhang_line += fruit + " "; } console.log("水果：" + zhang_line); // 也可遍历字符串 let zhang_name = ""; for (const ch of "张轩铭") { zhang_name += ch + "·"; } console.log("姓名：" + zhang_name);

🔁 for…in 循环

遍历对象的键名（包括原型链上的可枚举属性），常用于对象。

const zhang_student = { name: "张轩铭", age: 21, grade: "312" }; for (const key in zhang_student) { if (Object.prototype.hasOwnProperty.call(zhang_student, key)) { console.log(key + ": " + zhang_student[key]); } }

🔁 break & continue

break 立即跳出循环；continue 跳过本轮，继续下一轮。

// break：找到第一个大于 3 的数就停 let zhang_a = 0; for (let i = 1; i <= 10; i++) { if (i > 3) { zhang_a = i; break; } } console.log("break 结果：" + zhang_a); // continue：跳过偶数，只打印奇数 let zhang_b = ""; for (let i = 1; i <= 6; i++) { if (i % 2 === 0) continue; zhang_b += i + " "; } console.log("continue 结果：" + zhang_b);
